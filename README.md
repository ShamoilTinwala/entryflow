# EntryFlow

Event guest and gate-pass management UI. This is a local React prototype: events, host quotas, guest passes, and gate scans are stored in the browser. There is no backend yet.

## Run

```bash
npm install
npm run dev
```

Open the app, sign in with any valid email and a password of at least 4 characters, then use Events, Hosts, Scanner, Live Stats, and Settings.

## Stack

Vite, React 19, React Router 7, Tailwind CSS 4, React Hook Form, Zod, Sonner.
